# FlyEase-
A responsive flight booking system built using HTML, CSS, Bootstrap 5, and JavaScript. It includes flight search, seat selection, passenger details, fare calculation, demo payment, booking confirmation, and boarding pass generation.


# ✈️ FlyEase – Flight Booking System

A responsive flight booking website built using HTML, CSS, Bootstrap 5, and JavaScript.

## 🚀 Features

* 🔐 Login and Registration
* ✈️ Domestic and International Flight Search
* 🔄 One-Way and Round-Trip Booking
* 🔎 Flight Filtering and Sorting
* 💺 Seat Selection
* 👤 Passenger Details
* 🧳 Baggage and Meal Selection
* 💰 Fare Calculation and Tax
* 👴 Senior Citizen Discount
* 💳 Demo Payment System
* ✅ Booking Confirmation
* 🎫 Boarding Pass Generation
* 🖨️ Print Boarding Pass

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* LocalStorage

## 📂 Project Pages

* `index.html` – Home Page
* `login.html` – Login and Registration
* `flights.html` – Flight Search
* `seat.html` – Seat Selection
* `extras.html` – Baggage and Meals
* `passenger.html` – Passenger Details
* `payment.html` – Demo Payment
* `confirmation.html` – Booking Confirmation
* `boarding-pass.html` – Boarding Pass
* `script.js` – JavaScript Functionality

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Explore the flight booking process.

## ⚠️ Disclaimer

This is a college demonstration project. Flight information and payment functionality are for demonstration purposes only. No real flight bookings or payments are processed.
